# PolarCore CNC

<img width="300" height="300" alt="PolarCore_Logo" src="https://github.com/user-attachments/assets/204f24b1-5452-45e4-bcfd-54c72b7fad95" />

A custom-built, rigid desktop 3020 fixed gantry CNC router designed for aluminum milling.

## ⚙️ Specifications
- Current Work Area: X: 225mm, Y: 170mm, Z: 75mm
- Frame Structure: Aluminum extrusion & custom plates
- Motion: T8 lead screws with NEMA 23 stepper motors
- Controller/Electronics: TB6600 stepper drivers and STM32F411CEU6(Black Pill) running grblHAL

Work in progress. Assembly guides, BOM, and wiring documentation will be added as the project is rebuilt and tested.
